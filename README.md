# Slaite releases

Downloads for [Slaite](https://slaite.bymayo.co.uk): plan features, ship them with agents.

**[Download the latest version →](https://github.com/bymayo/slaite-releases/releases/latest)**

Grab the `.dmg` for your Mac (`aarch64` for Apple silicon, `x64` for Intel), open it and drag Slaite into Applications. Slaite checks this page for updates by itself, so you only need to download it once.
